## 2. The concept as the field holds it

What the field calls "coding style" today is two separate things, and neither is about how a person thinks.

1. **Style as layout and lint, enforced by machines.** Style guides and automatic formatters fix how code looks:
   PEP 8 for Python (2001), `gofmt` shipped with Go (2009), Prettier (2017), Black (2018). They are run in continuous
   integration and settle arguments about spacing and naming case. *General knowledge.* They judge the shape of a
   line, never whether the line follows the order in which the writer reasoned.
2. **Readability as fluent interfaces.** Method chaining that "reads nicely" is common (LINQ, Java streams are named in
   the record's own comparison, `stz-managing-deep-lists-narration.md` line 313). The record itself draws the line:
   NNL's claim "is NOT 'make APIs read nicely' (fluent interfaces do that)" (`base/doc/design/NNL_REVIEW.md`, 2026-07-10,
   a session's review).
3. **The AI age.** Code assistants arrived in mainstream editors from 2021 (GitHub Copilot's preview, *general
   knowledge*); by 2026 coding agents read, edit and run code themselves. The site names them as the field: "Coding
   agents such as Claude Code, Codex or Cursor come with their own tools" (`stzsite/content/en/coding-agents.md`, line
   12, read 2026-10-08; see Hazards on naming). The record's own design document states the fact the law chapter opens on:
   "Most programming today is done by agents and LLMs, not humans." (`SOFTANZA_INTELLIGENCE_ARCHITECTURE.md` LAW 6,
   "captured 2026-07-13 from the author's directive"). The field's answer to the quality of generated code is checking
   after the fact; the record's own field table puts it as "Validate after generation, retry on failure" against
   Softanza's "Constrained decoding" (`stz-agents-that-cannot-hurt-you-narration.md`, line 345, 2026).

The record's framing of the loss, in the author's narration: "The code prioritizes the machine's needs over the
programmer's natural expression." (`stz-near-natural-language-programming.md`, line 21).

## 5. The decision, and what was refused

The author's own words are marked **A**; a session's (study, charter, design document) **S**.

1. **Every line written WITH Softanza must take the historic style; the library's implementation is let go.** A, as the
   study reports the author's question (12.16): "The implementation code the AI wrote is accepted as good. But every
   line a programmer, human or agent, is asked to write with Softanza ... must embrace the historic style". (The quote
   exists only in the study; no Central memo carries it.) What was refused: reviving the style inside the library's
   code. The study measures why it differs: `_var_` locals at "415 per thousand lines in the library against 3.8 in the
   archived string class", a convention documented because Ring's scoping lets a library local overwrite a caller's
   global (`base/doc/internals/stz-_var_-convention-internal.md`).
2. **The `Then` detour, and the return of the classic form.** S. Why the detour was made, in the helper's own header:
   "previous suites use bare `? expr = expected` ... hard to read and doesn't distinguish 'ran but failed' from 'didn't
   run'" (`base/test/_narrated.ring`, lines 6-8). Measured cost (12.16): 988 classic blocks rewritten into
   `Scenario`/`Then`; narrated guards carry `#-->` at 0.7 per thousand lines against 75.1 in the narrations. Why it can
   return: Testoor TR2 ported the promise rules to Ring, "TRUE/FALSE as 1/0 ... a promise that argues with itself is
   PROSE -- unjudged, never diverged" (CONCLUSIONS 2026-10-05 20:57, 46 assertions). The study's ruling: the revival
   "is not a rewrite; it is a decision that the classic form is the one form for new blocks" (12.16); refused: "a second
   rewrite is churn" (B23). The test tree's README still says the classic form is "The authoritative test surface"
   (`base/test/README.md` line 3). **No author ruling on B23 found** (see [AUTHOR] 1).
3. **Code is renamed, never rewritten in its forms.** A (12.21, ruled by the author 2026-10-07 22:40 UTC): the rewrite
   is "a rename of the language's name and nothing else"; the amended site rule: "code is rewritten in the language's
   name and never in its forms".
4. **The style made machine-checkable, not folklore.** S capturing A (LAW 6, 2026-07-13): the house rules "exposed as
   validators an agent can RUN before committing code, not folklore it must infer". The library's own verdict on that
   row: "**CLOSED.** They are runnable: `meta/stzCodeRule(s)` ..." (`SOFTANZA_INTELLIGENCE_ARCHITECTURE.md` line 482).
   What it does not close: a court for the programmer's style (12.16, B22, specification).
5. **One meaning per suffix; three 2022 features refused as grammar in Haro.** S (Haro principle 7, "[D] designed",
   `ringpp/haro/PRINCIPLES.md`): "Refused as grammar: the misspelled form, free-order parameters, per-language method
   names, and the `FF` clash (one meaning per suffix)." Rung twelve built it on the author's "continue" (2026-10-03):
   stzString's 595 shipped spellings judged live, "584 agree, 11 do not, 41 generated members are not shipped"
   (`CHARTER.md` lines 264-270). Tension with the 2022 deck, which counted misspelling tolerance, free order and
   multilingual functions as features (12.2, 12.14). Whether the refusal is the author's: [AUTHOR] 2.
6. **No natural syntax in the grammar; no `eval`.** S (Haro principle 8, rules 3-4): "The natural door ... parses,
   refuses, and emits a Haro program the compiler judges. No `eval`." "4. No natural syntax in the grammar." The
   near-natural chains stay library methods (the human is the parser, `NNL_REVIEW.md`).
7. **Goals, not only laws.** S (12.14): "The skeleton of 2022 was goals; the skeleton of 2026 is laws. A law says how, a
   goal says why". The 6,090 `#< @Function…Forms >` info-tags carry "about eighty-five other spellings" and "No guard
   reads them" (12.14). Refused implicitly: no harvester; B16 proposes one.

## 7. The field, and where it leads

Where the field leads (the loss beside the win):
- **Formatters and linters are universal and enforced.** Every mainstream language has one, run in CI by default
  (*general knowledge*). Softanza's style court for the code a programmer writes is a specification only: "B22. A style
  court for the code a programmer writes ... Owner: stzlib. Specification." (12.16, 2026-10-07). Its writing grammar in
  Haro (B24) is "Routed to the Haro charter through Central".
- **Ecosystem and hiring.** "There is a labour market for that stack and none for this one."
  (`stz-agents-that-cannot-hurt-you-narration.md`, "Where the industry is genuinely ahead", 2026).
- **Generators.** "Frontier reasoning. That stack orchestrates the largest models per call." (same narration).
- **Agents reach little today.** "From outside, little reaches. An agent can run a script, but it cannot yet call a
  command that answers, judges or plans." The `stz` door is "Decided on 2 October 2026. Not built yet."

  five levels judged by guards (12.17).
- **Agent:** you will be corrected by the library, not by folklore (LAW 6); write the classic form, `?` then `#-->`,
