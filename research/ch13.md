## 2. The concept as the field holds it

**What is meant today.** In the field's common language, "programming in natural language" means one thing: asking a model for code, or asking it
to do the task, in a prompt. The tools are chat assistants and code completers (general knowledge: in wide use since about 2021-2022). What
the sentence runs on is the model's guess, so the same sentence may give different code on different days, the model needs a network or a local
runtime, and a person reads the result to know what was understood. The study says the same in its own words: "The field now equates
natural-language programming with prompting a model" is its reading, `drafts\stzsite-roots-and-achievements.md` section 12.27 ("The reading."),
ruled 2026-10-07 23:44 UTC. Chapter 11 §1 already says it; chapter 13 should not retell it, only point back.

**The older practices, which the record names.**
- *Inform 7*, a language whose programs are English sentences, compiled whole, with a world model and reference ("it") across sentences
  (general knowledge: designed by Graham Nelson, released 2006). The record's reading: "Inform 7 -- the one serious natural-language programming
  system -- is a whole-text *compiler* with referential context, not a command dispatcher": `D:\GitHub\softanza\memos\2026-08-30-ring-critical-analysis.md`
  section 6 ("The proof by replacement"), a session's reading, 2026-08-30.
- *AppleScript*, English-like and hard to write because "its naturalness was surface rather than semantic model": same memo and section (a session's
  reading; general knowledge: Apple, 1993).
- *Controlled natural languages* (general knowledge: Attempto Controlled English, from the 1990s; PENG). The library's own code names them: a comment
  above the suggestion vocabulary reads "The Ginseng/PENG lesson: the strongest CNL UX device is showing what CAN be said next",
  `base\natural\stzSemanticResolver.ring` line 538. The record does not date the borrowing.
- *Given/When/Then step languages* such as Gherkin (general knowledge: 2008), where a sentence is matched to code by patterns written by a person. This
  is the closest cousin of the near-natural chain (a person writes the code that the sentence names). Not in the record; mark as general knowledge or drop.

**What none of them is, and the record's claim.** The record's claim is the opposite of prompting: "a sentence executes because every word of it is in
a closed, data-defined lexicon mapped to a verb the library documents, and anything else is refused with the reason" (12.27, "The reading.", paraphrased
from the study; the quoted fragments are in section 3). Two directions exist, and the record holds a table of them (`NNL_REVIEW.md` section 1, reproduced in
section 4 of this file): the machine is the parser (`Naturally()`), or the human is the parser (near-natural chains).
