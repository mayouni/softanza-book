## 2. The concept as the field holds it

What "a method" means for a software project today, in three named practices. None of these is a record field study;
all three are **general knowledge**, and the writer should cite them as such or ask the author for a preferred source.

1. **Architecture Decision Records (ADRs).** A short document per decision: context, decision, consequences.
   Proposed by Michael Nygard in a 2011 blog post ("Documenting Architecture Decisions"). General knowledge. It is the
   field's closest form to the book's element 4 ("the decision, and what was refused"); the difference to draw: an ADR
   records a decision, it does not run.
2. **Executable examples in documentation.** Python's `doctest` module (in the standard library since Python 2.1, 2001)
   and Rust's documentation tests (`cargo test` runs code in doc comments). General knowledge. The field's closest form
   to the promise under an expression (`#-->`). The record's own house form is the same idea carried across a whole
   library: 9,311 promised examples (study 12.29, read from the record, not re-counted here).
3. **The feature grid.** Rows of dimensions, columns of tools, ticks and crosses. The record's own count (study 12.22):
   64 grids, 615 rows, in 31 documents of the library; Softanza's column 286 ✅, 2 ⚠️, 2 ❌, the others 204 ✅, 207 ⚠️,
   269 ❌. The study calls the grid alone "the shape of a brochure" and notes the record itself does not trust it.

On "first principles" as a phrase: in the industry it is a slogan for reasoning from fundamentals rather than by
analogy (general knowledge; avoid attributing it to a named person without a source). The record uses it in a
narrower, checkable sense: a named concept, its field form, its redesign, and the code that carries it (see §3, §4).

A field contrast the writer can run in a minute (run here, 2026-10-08, Python 3.13.15 and Node v22.20.0):

```
python: 'text'.count('')  -> 5      '' in 'text' -> True     'text'.find('') -> 0
node:   'text'.includes('') -> true   'text'.indexOf('') -> 0
```

This is the field's default for emptiness, against which the emptiness narration's rules are the rethink (block D).
